# Fisicks (Pre-Alpha)
A Physics Olympiad progress tracker and planner

## About

This project is a school project, so don't expect long-term software support, or get your expectations too high.

*Fisicks* is a physics olympiad progres tracker and planner, with the purpose of helping students reach their goals in PhOly, through mainly, but not limited to including a planning and logging systems specially mode for PhOly.
